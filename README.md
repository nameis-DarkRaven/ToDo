# ToDo
A to-do app for tracking tasks in all phases of life. 


# Features Goals
## Modules
*? represents optional column in list*
- [ ] Default Setup Modules
  - [ ] Basic ToDo List
    - [ ] Due Date?
    - [ ] Do Date?
    - [ ] Done
  - [ ] Due Date Calendar
  - [ ] Do Date Calendar
  - [ ] Weekly Calendar
  - [ ] Notes List
- [ ] Academic Modules
  - [ ] Academic ToDo List
    - [ ] Class
    - [ ] Assignment
    - [ ] Due Date
    - [ ] Do Date?
    - [ ] Est. Time?
    - [ ] Done
  - [ ] Class Time Tracking
- [ ] Home Modules
  - [ ] Grocery List
  - [ ] Travel Plans List
    - [ ] When
    - [ ] Where
    - [ ] How
      - [ ] Flights option
      - [ ] Drive option
    - [ ] Link to Notes or smth

## Capabilities
- [ ] Starts with one each of the Default Setup Modules
- [ ] Ability to delete and add modules to workspace
- [ ] Ability to create modules from module blocks
- [ ] Add tasks to lists
- [ ] Add scheduled tasks/events to calendar
- [ ] Color code tasks/events on calendar
- [ ] Ability to jot down quick notes both related to tasks/events and on their own
